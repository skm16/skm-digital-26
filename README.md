# SKM.digital

Marketing site for SKM.digital — independent studio, Woodbury CT.

Built with **Astro 5** (mostly static, one server endpoint), deployed to **Cloudflare Workers**
using the new "Workers + Static Assets" model (the unified successor to Pages).
Contact form submissions are spam-gated by Cloudflare Turnstile and delivered via Resend.

## Stack

- **Astro 5** — static homepage, with a single on-demand endpoint at `/api/contact`
- **`@astrojs/cloudflare`** — adapter outputs a Pages-compatible build
- **Resend** — transactional email (skm.digital domain already verified)
- **Cloudflare Turnstile** — invisible-by-default CAPTCHA
- **Zod** — request validation
- **Sharp** — local-only image and meta-asset pipeline (run on demand)

## Local development

```bash
npm install
cp .dev.vars.example .dev.vars   # then fill in real keys
npm run dev                       # http://localhost:4321
```

The Cloudflare adapter reads `.dev.vars` for runtime secrets in dev. Keys you'll need:

- `RESEND_API_KEY` — from <https://resend.com/api-keys>
- `CONTACT_FROM_EMAIL` — verified Resend sender on skm.digital (e.g. `"SKM.digital <contact@skm.digital>"`)
- `CONTACT_TO_EMAIL` — inbox where inquiries land (e.g. `sean@skm.digital`)
- `TURNSTILE_SECRET_KEY` and `PUBLIC_TURNSTILE_SITE_KEY` — from <https://dash.cloudflare.com/?to=/:account/turnstile>

## Build

```bash
npm run build      # outputs to /dist (Astro)
npm run preview    # runs `wrangler dev` against the built dist
npm run deploy     # `astro build && wrangler deploy` — used by CI
```

## Deploy (Cloudflare Workers + Static Assets)

The deploy contract is defined in [`wrangler.jsonc`](./wrangler.jsonc):
the static homepage + assets ship from `dist/`, and `dist/_worker.js/index.js`
is the Worker entry that handles `/api/contact`.

### One-time setup in the Cloudflare dashboard

1. **Workers & Pages → your project → Settings → Build**
   - **Deploy command:** `npm run deploy`
     (the default `npx wrangler deploy` skips the Astro build — that's what causes the
     "Asset too large / 118 MiB workerd" error, because Wrangler tries to upload `node_modules` as static assets.)
   - **Build command:** leave blank (the deploy script handles it).
2. **Settings → Variables and Secrets**
   - **Plaintext / build-time:** `PUBLIC_TURNSTILE_SITE_KEY`
   - **Secret / runtime:** `RESEND_API_KEY`, `TURNSTILE_SECRET_KEY`, `CONTACT_FROM_EMAIL`, `CONTACT_TO_EMAIL`
3. **Settings → Domains & Routes:** add `skm.digital` and `www.skm.digital`.

### Deploy from your laptop (optional)

```bash
npx wrangler login        # one-time
npm run deploy            # build + push
```

```
  components/

  env.d.ts             # ImportMetaEnv typing for env vars
```

## Editing content

The page lives in [`src/pages/index.astro`](./src/pages/index.astro). Sections in order:

- `<nav class="top">` — wordmark, availability pill, social links
- `<section class="hero">` — animated headline + subheading + CTA (anchors to `#contact`)
- `<div class="marquee">` — scrolling capability list
- `<section class="work">` — 4-card project grid (screenshots in `/public/images`)
- `<section class="what">` — "What I Do" prose
- `<section class="clients">` — direct + agency client lists
- `<section class="kisho">` — featured Kisho long-bet section (auto-scrolling screenshot)
- `<section class="contact">` — heading + `<ContactForm />`
- `<footer>` — wordmark, socials, copyright

To swap a project screenshot: drop a new image into `/public/images/`, then update the `src` in the matching `<a class="project">` block.

## Design notes

- Color tokens live in `:root` at the top of the `<style is:global>` block (`--paper`, `--ink`, `--accent`, etc.)
- Fonts pulled from Google Fonts: Fraunces (serif), Geist (sans), JetBrains Mono (mono), Nunito (Kisho brand only)
- Paper-grain texture is an inline SVG data URI on `body::before` with `mix-blend-mode: multiply`
- Screenshot containers use `isolation: isolate` to prevent the grain from bleeding through


These don't run in CI — they're local-only utilities for when source images change.

## Why this stack

- **Static-first.** The homepage is prerendered HTML on Cloudflare's edge — fast everywhere, free.
- **One server endpoint.** `/api/contact` runs as a Pages Function only when called.
- **No third-party form vendor.** Submissions flow form → your code → Resend → your inbox. No iframe, no rerouting through someone else's server.
- **Spam-resistant.** Turnstile + a hidden honeypot field + length limits.
- **Reply just works.** The email's `replyTo` is set to the prospect — hit reply in your inbox and it goes to them, not back to your contact alias.
